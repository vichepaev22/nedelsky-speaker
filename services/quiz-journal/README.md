# Собственный журнал диагностики

Небольшой журнал без стороннего сервиса. Публичный тест и все исходники остаются в GitHub; записи хранятся отдельно на VPS. Отправка только после разрешения пользователя, без текстов ответов/контактов.

server.py использует стандартную библиотеку Python и SQLite. HTTP-сервер слушает исключительно 127.0.0.1:8768 за Nginx HTTPS: фиксированные маршруты, ограниченный размер/схема, Origin/CORS, rate limit и Basic auth для владельца. Это ограниченный MVP, не универсальный production HTTP-сервер. Пароль задаётся хешем QUIZ_ADMIN_PASSWORD_SHA256; база QUIZ_JOURNAL_DB вне репозитория.

Одна строка на визит: случайные UUID браузера/визита, quizId/revision, первое и последнее серверное время, последний экран/шаг, sequence, итоговый уровень и завершение. Повторные/старые sequence не перезаписывают новые. Хранение 30 дней, очистка каждый час, максимум 50 000 визитов.

Закрытая /quiz-stats/ страница: периоды 24 ч/7/30 дней, последние 500 визитов, CSV. Это учёт браузеров с разрешённой статистикой, не установление личности и не полный охват. Секреты, база, записи и локальный доступ владельца не публикуются.

Проверка: `python -m unittest discover -s services/quiz-journal -p "test_*.py"`. Тесты используют временную SQLite и localhost, производственные данные не затрагивают.
