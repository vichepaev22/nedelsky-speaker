# GEO: готовность сайта к чтению ассистентами

Проверено: 28 августа 2026.

## Реализовано

- Главная страница и четыре страницы программ генерируются со всем основным содержанием в исходном HTML. JavaScript только добавляет интерактивность, а не подгружает критический текст.
- В каждую страницу встроена описательная Schema.org-разметка в JSON-LD: `Person`, `ProfilePage`/`WebPage`, `Course` и `BreadcrumbList`.
- Добавлен `llms.txt` с кратким описанием эксперта, тем, форматов и канонических ссылок.
- На главной есть видимый раздел с ответами на частые вопросы, подтверждающий формат работы и способ связи.
- В текстах указаны конкретные компетенции, подтверждённые роли и партнёры, а у страниц есть дата обновления.

## Ограничения и следующий шаг

`llms.txt` — дополнительный открытый слой для машинного чтения; он не гарантирует упоминание или ответ конкретного ассистента. Для Яндекса после публикации следует добавить сайт в Яндекс Вебмастер и отправить карту сайта: `https://vichepaev22.github.io/nedelsky-speaker/sitemap.xml`.

У GitHub Pages сайт размещён в подпапке `/nedelsky-speaker/`. При подключении собственного домена нужно перенести `robots.txt` в корень этого домена и повторно отправить sitemap в Яндекс Вебмастер.
