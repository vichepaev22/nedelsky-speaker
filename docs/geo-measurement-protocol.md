# GEO: протокол наблюдения, не обещание рекомендаций

Дата подготовки: 27 ноября 2026. Новый /about/ ещё не опубликован. Независимый baseline не получен: **0 из 90 потенциальных проверок выполнено**, доли не рассчитываются. Текущий персонализированный чат, Exa и обычная поисковая выдача не подменяют ответы шести платформ.

## Как измерять

1. После релиза зафиксировать его дату и commit. Запускать запросы из `geo-queries.csv` в новых чатах без памяти/персонализации: ChatGPT Search, Алиса AI, Google AI/Gemini, Copilot, Perplexity, Claude с веб-поиском — только при фактическом доступе. Не обходить региональные ограничения и не покупать API-вызовы автоматически.
2. Сохранять точный запрос, модель/режим, включён ли поиск, язык/регион, дату, номер повтора, полный ответ или разрешённый скриншот и ссылки. Branded и unbranded считать отдельно. Режим без поиска — отдельная серия, не смешивать с поисковым.
3. По возможности 2–3 независимых повтора. Повторить через 7–14 дней, сохраняя параметры. Это инструкция, **не созданная автоматизация**.
4. В `geo-measurements.csv` вносить только реально полученные ответы. Если платформа недоступна, `valid_response=false`, остальные результативные поля пустые, причина в notes. Не записывать «не упомянул», если ответа не было.
5. Для каждого проверяемого утверждения сверяться с реестром источников: имя/отчество, сфера, реальная роль, дата, авторство. Не смешивать однофамильцев и давние спортивные проекты с текущими услугами.

## Метрики

- Упоминания = ответы с корректным упоминанием / валидные ответы.
- Рекомендации = рекомендации в небрендовых запросах / валидные небрендовые ответы.
- Цитирование сайта = ответы со ссылкой на `nedelsky.pages.dev` / валидные ответы. Ссылки на СМИ учитывать отдельно, не как цитату сайта.
- Точность = корректные проверяемые утверждения / все проверенные утверждения. Непроверяемое не считать правильным автоматически.
- Переходы и обращения — только фактические данные согласованной аналитики и владельца. Рост упоминаний сам по себе не доказывает рост продаж.

При нулевом знаменателе результат — «нет данных», не 0%. Не приписывать изменения одной доработке: меняются индекс, модели, сезонность и поиск. Дополнительно после подтверждения сайта можно использовать [видимость в Алисе AI](https://yandex.ru/support/webmaster/ru/service/alice-answers) и [Bing AI Performance](https://www.bing.com/webmasters/help/ai-performance-9f8e7d6c); их агрегаты не смешивать с ручной выборкой.
