# Schema.org: отчёт по разметке

Проверено: 28 августа 2026.

| Страница | JSON-LD | Статус |
| --- | --- | --- |
| Главная | `Person`, `WebSite`, `ProfilePage` | Встроено в исходный HTML |
| Страница каждой программы | `WebPage`, `Course`, `BreadcrumbList` | Встроено в исходный HTML |

В разметке используются только подтверждённые на сайте сведения: имя, роли, описание практики, темы программ, форматы, ссылка на VK и URL страниц. Цены, оценки, отзывы, адрес и неподтверждённые контакты намеренно не добавлены.
