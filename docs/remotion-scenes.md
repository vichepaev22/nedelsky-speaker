# Интерактивные сцены программ

В каждой программе есть 10-секундная сцена: ИИ, клиентский путь, партнёрство и закупочный цикл. Это иллюстрации подходов, а не реальные результаты клиентов и не юридические инструкции.

## Реализация

- `app/motion/program-scenes.ts` — тексты и параметры четырёх сцен.
- `app/motion/SceneArtwork.tsx` — SVG-схемы, общие для статичного HTML и анимации.
- `app/motion/ProgramMotionPlayer.tsx` — Remotion Player, 30 fps, 300 кадров. Анимация привязана к кадру через `useCurrentFrame` и `interpolate`, а не к CSS-таймерам.
- `app/ProgramInteraction.tsx` — доступные HTML-кнопки, отложенная загрузка, управление воспроизведением.
- `app/FormatExplorer.tsx` — сравнение глубины трёх форматов; подробные карточки программ сохранены.

Remotion загружается отдельным JS-файлом, когда до сцены остаётся не более 200 px. На главной странице Player не загружается. Воспроизведение идёт один раз, при выходе сцены из области просмотра и скрытии вкладки — приостанавливается. Явная пауза сохраняется. Выбор этапа останавливает сцену и показывает пример; повтор возвращает её в начало.

При `prefers-reduced-motion: reduce` Player не загружается и не монтируется; схемы и выбор этапов остаются доступными. Изменение этой настройки учитывается без перезагрузки. Если загрузка анимации не удалась, сохраняется статичная интерактивная схема.

На узких экранах схема перестраивается в сетку 2×2. Место под сцену заранее задано `aspect-ratio`. Текстовые панели занимают одну общую grid-ячейку с высотой по самому длинному описанию — переключение этапов не сдвигает страницу. Автоматическое воспроизведение не создаёт непрерывных объявлений screen reader; ручной выбор озвучивается через `aria-live`.

## Проверка

`npm run lint`, `npx tsc --noEmit`, `npm test`, `npm run test:pages`.

В браузере: все четыре темы на 1440 и 390 px; отсутствие горизонтального переполнения на 320/768/1024 px; выбор этапа, пауза, повтор, остановка вне экрана и скрытой вкладке; reduced motion; работа схемы при ошибке загрузки; отсутствие Player в сетевых запросах главной страницы.
