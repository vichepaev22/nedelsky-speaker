## Релиз по действующему процессу

1. Просмотреть PR и локальный `/about/`. Не переносить весь грязный исходный checkout: эта ветка изолирована.
2. После одобрения merge в main запускает существующий GitHub Pages workflow. Для Cloudflare использовать существующий проект `nedelsky` и проверенный `cloudflare-dist`, без `ai-quiz` (он остаётся только на GitHub). В этой задаче новый deploy/merge не выполнялся.
3. Проверить **публичные** `/about/`, главную, `/ai-for-business/`, 4 программы, `/legal/privacy/`, robots, llms и sitemap: 200, правильный HTML, canonical и Person. Затем повторить мобильный smoke test. Локальная сборка не доказывает публикацию.

## Вебмастера: без выдуманных ключей

Фактические права в панелях, индекс и собственность домена в этой работе не подтверждены. Авторизованный браузер Codex недоступен (GetCursorPos: отказано в доступе). Доступ к GitHub не означает доступ к панелям Яндекса/Google/Bing.

- [Яндекс Вебмастер](https://webmaster.yandex.ru/): выбрать/добавить `https://nedelsky.pages.dev/`. Если сервис выдаст HTML-файл или метатег, передать **точное** содержимое для размещения в public или head. После подтверждения и релиза отправить `https://nedelsky.pages.dev/sitemap.xml`, проверить URL `/about/` и раздел видимости в Алисе AI.
- [Google Search Console](https://search.google.com/search-console/): для общего домена `pages.dev` использовать свой **URL-prefix** `https://nedelsky.pages.dev/`, а не Domain property на чужой `pages.dev`. Подтвердить предложенным HTML-файлом/метатегом; после релиза отправить sitemap, проверить URL и запросить индексирование, если доступно.
- [Bing Webmaster Tools](https://www.bing.com/webmasters/): добавить тот же сайт, подтвердить фактически предложенным способом (или импортировать уже подтверждённый GSC), затем отправить sitemap и открыть AI Performance при доступности.
- IndexNow: только после подтверждения управления именно этим хостом и согласования. Разместить фактический ключ в корне сайта, проверить его доступность и отправить изменившиеся canonical URL согласно [официальной документации](https://www.indexnow.org/documentation). Ключ не создан и запросы не отправлялись. Не отправлять URL, которых ещё нет в production.

Сгенерировать рабочие файлы верификации до получения их точного содержимого невозможно. Не подставлять примеры вместо настоящего verification-кода.
