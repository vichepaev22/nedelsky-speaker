# Где я сейчас в ИИ — бесплатная диагностика

## Публичная версия: release18, 28.10.2026

Единственный публичный тест: https://vichepaev22.github.io/nedelsky-speaker/ai-quiz/ . Исходники и статический экспорт находятся в этом репозитории. Округлая кнопка «Где я в ИИ?» ведёт на этот абсолютный адрес. Cloudflare не содержит копию теста; в этом релизе публикация разрешена только на GitHub Pages.

- Принятый дизайн, 3 вопроса знакомства + 16 оцениваемых ситуаций, персонаж и главы с 5/10/15/20 шариками. На телефоне обычная прокрутка придаёт шарикам импульс; короткий вход и два приглашения конечны. Клавиатура, reduced-motion, скрытие страницы и смена экрана останавливают эффекты.
- Расчёт в браузере сохраняет прежние индекс, half-even округление, четыре шкалы и последовательные ворота. Это самооценка практики, без экзамена или сертификата.
- SWOT после шкал: четыре карточки с разовыми вводными, пунктами без повторов и раскрываемыми точными основаниями из ответов. Согласованные ряды двух колонок, на телефоне одна колонка. SWOT входит в TXT/сохранённую карту/печать. Модель ИИ не вызывается.
- Ответы: sessionStorage до 24 часов; при блокировке storage тест работает в памяти. Сохранение карты в localStorage только по кнопке. Сырые ответы, контакты и тексты SWOT не отправляются в статистику.
- Собственный необязательный журнал: только после выбора «Разрешить статистику» — случайный код браузера/визита, серверное время, версия теста, последний экран/шаг и итоговый уровень. При отказе тест полностью доступен. Сервер отдельно на VPS; недоступность сервера не мешает прохождению. Срок хранения 30 дней, техническая очистка каждый час; не более 50 000 визитов. Настройки/код браузера 180 дней, визит 24 часа. Подробности: public/ai-quiz/privacy.html.
- Закрытый журнал владельца: отдельная HTTPS-страница с паролем, последние 500 визитов, периоды 24 ч/7/30 дней и CSV. Пароли и база не включаются в Git. Посетитель — анонимный браузер, не установленная личность; отказ и блокировщики означают неполный охват.
- «Анализ бизнеса с ИИ»: 4 500 ₽, в течение 90 минут после завершения — 2 900 ₽; обсуждение через https://vk.ru/ndlsky . Повторный тест/refresh не продлевает существующее предложение. Ключ nedelsky-business-analysis-offer-v2. Отдельная запись на консультацию без указанной цены.
- Встроенных платежей, автоматической AI-генерации, email, бота и сторонней аналитики нет. Telegram не добавлен без реального аккаунта владельца.

Экспорт: `python ai-maturity-quiz/scripts/export_static.py --out public/ai-quiz` (Jinja2 из quiz .venv). Файлы public/ai-quiz включены только в GitHub build. build-manifest.json фиксирует хеши; .gitattributes сохраняет байты.

Проверки: `npm run test:pages`, `npm run test:cloudflare` (проверяет исключение копии теста, не публикует), `npm run test:quiz`, `python -m unittest discover -s services/quiz-journal -p "test_*.py"`, lint/tsc и существующие проверки сервера. Фикстуры117 защищают совпадение JS/Python scoring. Платёжные условия при оформлении подтверждает владелец, клиентский таймер не авторизует оплату.

## История: локальная серверная версия

# Диагностика «Насколько эффективно вы используете ИИ?»

Локальный рабочий MVP по `AI_Quiz_Codex_TZ.md` v1.0 от 23.10.2026. Находится в репозитории сайта Максима Недельского, но **не включён в сборки Cloudflare/GitHub Pages и не опубликован**. Основные страницы и цены не меняются. Интерфейс полностью переработан по `DESIGN.md`: белые/холодные поверхности, near-black текст и кнопки, одна системная sans-гарнитура с кириллицей; четыре мягких игровых акцента. Источник правил — Cal.com analysis из VoltAgent/awesome-design-md, адаптированный под эту диагностику.

## Запуск в PowerShell

Из папки `ai-maturity-quiz`:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 4180 --no-access-log
```

Открыть [http://127.0.0.1:4180/](http://127.0.0.1:4180/). Активация окружения и изменение ExecutionPolicy не нужны. Сервер слушает только этот компьютер; туннель и публичный доступ не открываются. Ctrl+C завершает процесс.

Проверки:

```powershell
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider
.\.venv\Scripts\python.exe -m pip check
node --test --test-isolation=none tests/chapter-physics.test.mjs tests/roadmap-offer.test.mjs
```

Установленное изолированное окружение: Python 3.14.0, FastAPI 0.161.1, Starlette 1.9.0, Jinja2 3.1.6, Uvicorn 0.54.0, pytest 9.1.1, HTTPX 0.28.1. Поддерживается Python 3.12+. Документация FastAPI через Context7 `/websites/fastapi_tiangolo`: `Jinja2Templates.TemplateResponse(request=...,name=...,context=...)`, StaticFiles, cookies, TestClient. Сигнатура установленной версии проверена. TestClient выдаёт предупреждение Starlette о будущем переходе с HTTPX на HTTPX2; проверки проходят, предупреждение не скрыто. Зависимости основного React-сайта не обновлялись. ESLint исключает только Python `.venv`.

## Что работает

- Обложка → 3 контекстных вопроса → 16 диагностических → четыре варианта результата.
- По одному вопросу; явная кнопка перехода, назад, автосохранение выбора, refresh и повторное прохождение.
- Четыре главы и короткие переходы без таймеров и оценивания.
- Все баллы и последовательные «ворота» рассчитывает сервер. Браузер отправляет ID вопроса/ответа, а не баллы. Присланные лишние поля отклоняются.
- Индекс ответов отдельно от текущей ступени. Четыре шкалы, сильный блок, зона роста, объяснение непройденных ворот, три шага на 7 дней и пример под выбранную цель.
- До результата нет контактов или paywall. Основная связь — известный ВК; при пустой ссылке диагностика оформляется через известный ВК. Рекомендованный продукт ведёт на существующую страницу с `?product=...#details-...` и не является обязательной покупкой.
- «Сохранить результат» сохраняет текст карты и дату в этом браузере **только после нажатия**. На обложке можно увидеть/удалить предыдущую карту; перезапуск теста не удаляет её. Дополнительно можно скачать `.txt`. При заблокированном хранилище доступен текстовый файл. Межустройственной синхронизации нет.
- Формы и результат работают без JavaScript; JS добавляет автосохранение, перенос фокуса и локальное сохранение карты. Без JS ответы сохраняются по кнопке «Далее», а карту можно сохранить через браузер.

## Редактирование

Актуальный дизайн-контракт: `DESIGN.md`, изменение `QUIZ-DESIGN-MD-07` в `.smol/intent.md`. Полный путь (обложка, знакомство, вопросы, главы, результат, ошибка, сохранённая карта) использует единые токены/состояния. Названия предложений 23–24 px, текст 16 px, пояснения 14 px. Короткие CTA рядом с ценой; состав ниже. Без внешних шрифтов и новых UI-зависимостей.

Оформление двух предложений: `app/static/offers.css` загружается только на результате, `offers-motion.js` добавляет однократный вход карточек; оформление по `emil-design-eng`. Обе карточки светлые с тёмным текстом; дорожная карта выделена тонкой синей рамкой, консультация — нейтральной поверхностью. Это заменяет прежнюю тёмную карточку консультации. С клавиатуры/reduced-motion движения нет.

Переходы глав: `app/static/chapter-motion.js` и чистая модель `chapter-physics.mjs`. На обложке четыре направления, после знакомства — 5 шариков, перед главами 2/3/4 — 10/15/20 шариков. Они движутся по двум осям в области главы, отскакивают от видимых строк текста, кнопок, краёв и соседей. В покое и на скрытой вкладке цикл останавливается; reduced-motion и клавиатура дают статичный вариант, touch не перехватывается. Человечек виден с первого вопроса: три шага знакомства, затем 16 шагов диагностики; его короткая ходьба не зациклена.

На результате — отдельные карточки дорожной карты (3 000 ₽, 2 000 ₽ при оплате в течение 90 минут) и консультации (90 минут, 4 500 ₽). Кнопки открывают настроенные внешние адреса; при пустом `DIAGNOSTIC_URL` карта ведёт в известный ВК для запроса ссылки на оплату. Реальная оплата/автоматическая AI-генерация/доставка не подключены. Срок подготовки согласуется по задаче.

`roadmap-offer.mjs` хранит только начало/конец предложения в localStorage `nedelsky-roadmap-offer-v1`; обновление страницы и новый тест не перезапускают 90 минут. При ошибке storage или истечении остаётся 3 000 ₽. Это демонстрация интерфейса, а не защита платёжной скидки: проверку срока/цены должен выполнять будущий checkout на сервере. Не использовать локальный таймер как доказательство допустимости цены.

- `app/questions.py`: все 19 вопросов и их варианты. Баллы, IDs и порядок должны сохранять инварианты тестов.
- `app/scoring.py`: индекс (Python `round`, как в псевдокоде ТЗ), четыре шкалы, пороги, последовательные ворота P/S/A, приоритеты сильного/растущего блока.
- `app/content.py`: тексты четырёх результатов, рекомендации и примеры по цели.
- `app/templates/`: обычный Jinja2 HTML; `app/static/styles.css` и `app/static/app.js` — оформление и поведение отдельно.
- `app/config.py`: настройки. Пример переменных — `.env.example`; для своих настроек создайте локальный `.env` (в Git не попадает), перезапустите сервер. Ссылки допускают HTTPS или пустое значение, без выдуманных адресов.

## Данные и безопасность

Анонимные ответы находятся в памяти одного процесса до истечения TTL (по умолчанию 24 часа), без продления при каждом действии. Cookie хранит только случайный подписанный ID, HttpOnly/SameSite=Lax. Серверный рестарт стирает сессии — это прямо указано на обложке. Старые записи очищаются при обращении и при создании новых; число активных сессий ограничено. Сервер не запрашивает имя, телефон, email и не отправляет данные внешним сервисам. Access log отключён командой запуска; аналитики и базы лидов нет. Поэтому миграции/ключи AI/оплата/почтовый провайдер не нужны.

CSRF token нужен для всех POST, проверяются Origin и Fetch Metadata. Размер тела и частота изменений одной сессии ограничены. Политика `Referrer-Policy: same-origin` сохраняет Origin внутренних HTML POST и не передаёт referrer внешним сайтам: [MDN — влияние Referrer-Policy на Origin](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Referrer-Policy#effect_on_the_origin_header). В браузере выявлен и регрессионно исправлен конфликт исходного `no-referrer` с проверкой Origin; защита от чужого Origin/неверного CSRF не ослаблена. Jinja2 экранирует строки; CSP запрещает сторонние скрипты/формы/frames, ответы no-store. Шкала — авторская ориентировочная модель, не научная аттестация.

`LEADS_ENABLED` и `ANALYTICS_ENABLED` должны оставаться false. При попытке включить приложение остановится с понятной ошибкой: эти возможности нельзя случайно активировать без отдельной реализации и необходимых согласий. `RETENTION_DAYS` зарезервирован для будущих лидов и не управляет сессиями; сейчас используется `SESSION_TTL_HOURS`. Локальный сохранённый результат остаётся до явного удаления или очистки данных браузера.

## Перед публикацией — после отдельного одобрения

Python не исполняется на статическом Cloudflare Pages. Нужен Python/ASGI-хостинг либо отдельное решение о переработке серверной части. Не копировать эту папку в `cloudflare-dist` как «готовый сайт» и не считать её уже доступной в интернете.

Для первого размещения: выбрать отдельный Python-сервис и адрес, установить приложение, запустить Uvicorn за HTTPS-прокси одним процессом, задать постоянный случайный `APP_SECRET`, `COOKIE_SECURE=true` и реальные URL. Только после проверки конфигурации HTTPS/прокси, уведомления о данных и политики добавить ссылку с основного сайта. Для нескольких процессов/рестартов без потери прогресса понадобится общее TTL-хранилище вместо памяти процесса; для публикации — отдельная проверка защиты от массового создания сессий на уровне прокси. Изменения политики сайта, объявления, платная диагностика, лиды и публикация в этом локальном задании **не выполнялись**.

Источник принятого объёма: `.smol/intent.md` → `QUIZ-01`. Фактическая приёмка и скриншоты: `.smol/validation.md` и `.smol/quiz-*.png` в корне репозитория.
